I had wanted a personal website for years. Not a portfolio assembled from a template, but a place that felt like mine: a record of projects, questions, and things I was still figuring out.

The obstacle was never the idea. It was translating that idea into a system I could actually maintain.

![A three-step workflow from an idea, through an AI conversation, to a working website.](/blog-media/building-a-personal-website-using-ai/workflow.svg "The process was less “generate a website” and more a sequence of small, inspectable decisions.")

## AI changed the starting point

Instead of beginning with a blank editor, I began with a conversation. I described the experience I wanted, inspected the result, and made one decision at a time.

> The useful shift was not “AI can build my website.” It was “AI can help me reason through each layer of the website.”

### The working loop

- Describe the intended outcome in plain language.
- Inspect what the code actually does.
- Change one decision at a time.
- Test locally before publishing.

## What each tool was good at

| Stage | AI helped with | I remained responsible for |
| --- | --- | --- |
| Direction | Generating options | Choosing the experience |
| Implementation | Writing and explaining code | Reviewing behavior |
| Publishing | Diagnosing build errors | Approving each release |
